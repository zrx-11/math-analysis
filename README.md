## 关键公式的独立复核

正文中的例题结果均单独验算过，与课件一致，几处容易出错的地方记录在此：

- 第二型曲线积分例 1（`∫xy dx+(y-x)dy`，`A(1,1)→B(2,3)`）：直线 `25/6`、抛物线 `10/3`、折线 `-8/3`。
- 第二型曲线积分例 5（`∫2xy dx+x²dy`）：三条路径同为 `1`，因为被积式是 `d(x²y)`。
- 螺旋线做功：`-2πa²+2π²b²`。
- `∬_D x²e^{-y²}dσ`：`1/6-1/(3e)≈0.0441`。
- `∬_D |xy-1/4|dxdy`（`D=[0,1]²`）：`3/32+(ln2)/8≈0.180`，并用 4000×4000 网格数值积分复核。
- 直交圆柱体积：`16a³/3`。

## 重新构建

内容与样式分离，改内容后重新生成：

```bash
python3 insert_chapters.py
```

| 文件 | 职责 |
|---|---|
| `build_skeleton.py` | 生成骨架：KaTeX（CSS+JS+字体 base64 内联）、布局、导航与交互 JS，末尾留 `<!-- REST_CHAPTERS -->` 锚点 |
| `chapters_a.py` ~ `chapters_e.py` | 五批章节内容（各定义 `CH_A`~`CH_E` 字符串），新增章节写在 `chapters_e.py` |
| `insert_chapters.py` | 依次加载五批内容替换锚点，输出最终 HTML；幂等（锚点缺失时自动重跑骨架） |
| `pdf_text/` | 源 PDF 的文本提取（PyMuPDF），只用于核对章节结构、定理编号 |
| `shots21/` | 关键页的 2 倍渲染图，用于核对公式与例题 |
| `fonts/` | KaTeX woff2 字体（构建时 base64 内联，勿删） |

新增章节时需要同步改三处：`build_skeleton.py` 的 `CHAPTERS` 列表、章节文件里的 `<span class="num">` 编号、`insert_chapters.py` 的加载批次。

**改完 `chapters_*.py` 必须重跑 `insert_chapters.py`**，磁盘上的 HTML 才会更新。
