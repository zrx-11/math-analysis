## 内容结构（11 章）

1. 课程概览（知识树、学习路径）
2. 数学地基：从初中开始（斜率→导数→偏导→定积分→行列式→点积 + 工具补全：求导法则/中值定理/部分分式/arctan/叉积/克莱姆法则/均值不等式/求根公式/基本定理直觉）
3. 隐函数（`y'=-F_x/F_y` 的完整推导、二阶导数、隐函数极值）
4. 隐函数组（雅可比、克莱姆法则、反函数组、极坐标/球坐标变换）
5. 几何应用（切线、法平面、交线切向量、切平面、梯度=法向量）
6. 条件极值（拉格朗日乘数法完整推导、无盖水箱、自拟题）
7. 含参量正常积分（连续性/可微性/可积性、积分号下求导、换序）
8. 含参量反常积分（一致收敛、M/狄利克雷/阿贝尔判别法、狄利克雷积分、φ(r) 高斯例）
9. 欧拉积分（Γ 函数递推、Γ(1/2)=√π、B 函数、B=ΓΓ/Γ）

11. 知识图谱与自测（思考题带答案）

每章包含：生活直觉绿色提示框、完整推导折叠框（默认折叠，逐行展开）、数值例子、前置/后续知识标注、章末"上一章/下一章"按钮、常驻目录导航。

## 教学设计原则

- **从初中出发**：每个概念逆推前置依赖直到四则运算/常识，再正向逐层构建。
- **推导不跳步**：代数每一步都写出，符号第一次出现给白话解释（Σ、sgn、arctan、ln、弧度制……）。
- **卡点模拟**：以"初二数学中等偏下、需掰碎喂"的学生视角遍历全文，主动补前置、补中间步骤、补直觉。
- **公式可验证**：关键结论配数值例子，重要积分配完整推导（高斯积分极坐标技巧、`∫e^(-px)sin(ax)dx` 两次分部积分、曲线积分例 4 全计算）。

## 重新构建

内容与样式分离，改内容后重新生成：

```bash
python3 insert_chapters.py
```

流程说明：

| 文件 | 职责 |
|---|---|
| `build_skeleton.py` | 生成含 KaTeX（CSS+JS+字体 base64 内联）与全部布局/导航/交互 JS 的骨架（含 `<!-- REST_CHAPTERS -->` 锚点） |
| `chapters_a.py` / `chapters_b.py` / `chapters_c.py` / `chapters_d.py` | 四批章节内容（各定义 `CH_A`~`CH_D` 字符串） |
| `insert_chapters.py` | 加载四批内容替换骨架锚点，输出最终 HTML（幂等：锚点缺失时先重跑骨架） |
| `pdf_text/` | 8 个源 PDF 的文本提取（PyMuPDF），内容校对依据 |
| `fonts/` | KaTeX woff2 字体（构建时 base64 内联进 CSS，勿删） |

**修改任何 `chapters_*.py` 后必须重跑 `insert_chapters.py`**，磁盘 HTML 才会更新。
