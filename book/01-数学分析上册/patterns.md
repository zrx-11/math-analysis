# 解题模式库（上册）

## 求极限的六种方法

1. **直接代入**：函数在点连续时，代入即得。
2. **消去零因子**：分子分母同除或分解，如 $\frac{x^2-1}{x-1}=x+1$。
3. **等价替换**：乘除位置换等价无穷小；加减位置先通分。
4. **洛必达**：$\frac00$ 或 $\frac\infty\infty$，且导数比极限存在。
5. **夹逼**：找上下界，两端同极限。
6. **泰勒展开**：含 $\sin x-x$、$e^x-1-x$ 这类需要看高阶项的式子。

判断顺序：先代入，再化简，再等价，再洛必达，最后泰勒。跳步容易错在等价替换的范围上。

## 证明不等式的四条路径

- 作差或作商，化到熟悉形式。
- 用单调性：移项构造函数，求导看符号。
- 用中值定理：把差写成 $f'(\xi)$ 乘以区间长度。
- 用泰勒展开：需要精确到二阶或更高阶时。

## 判断可积的三步

1. 查连续：闭区间连续直接可积。
2. 查间断：有限个第一类间断点仍可积。
3. 查振幅：以上都不满足时，回到 $\overline S-\underline S$ 估计。

## 反常积分的判别流程

1. 定类型：区间无限还是函数无界，瑕点在哪。
2. 找参照：与 $x^{-p}$ 比较，确定 $p$ 的临界值。
3. 查绝对值：先判绝对收敛。
4. 查本身：绝对值发散时改用狄利克雷或阿贝尔。

## 常见错误清单

- ε-N 证明里把 N 写成依赖 n。
- 等价替换用在加减法上。
- 洛必达连用前不检查是否仍是未定式。
- 换元后不回代（不定积分）或忘了换限（定积分）。
- 参数方程二阶导少除一个 $\varphi'(t)$。
