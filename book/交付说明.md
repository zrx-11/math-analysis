# 华东师大《数学分析》第五版 · 交付说明

## 一、这是什么

上下册 23 章的点化学习系统，含 12 个概念页、46 道测验、46 张抽认卡、65 条术语、2 份速查表与模式库，总入口 `index.html`。

## 二、目录结构

| 路径 | 说明 |
|---|---|
| `index.html` | 总学习手册（470 KB，单文件） |
| `index.md` | Markdown 导航 |
| `README.md` | 部署与使用说明 |
| `.nojekyll` | GitHub Pages 关闭 Jekyll |
| `00-跨书总览/` | 学习路线 / 概念映射 / 综合检验 |
| `01-数学分析上册/` | 第 1–11 章 + 6 概念 + 伴侣 HTML |
| `02-数学分析下册/` | 第 12–23 章 + 6 概念 + 伴侣 HTML |
| `_scan/` | 目录页渲染图与 OCR 文本（过程产物） |

## 三、怎么用

双击 `index.html`，在侧边栏选择书目；章节页有前置知识条与出处脚注；测验答错会给出根因概念；进度在本地保存。

## 四、部署 GitHub Pages

已推送到 `zrx-11/math-analysis` 的 `book/` 子目录，根目录原有 18–21 章课程保持不变。访问 `https://zrx-11.github.io/math-analysis/book/`。

若要独立部署：把 `book/` 内全部文件放到仓库根，Settings → Pages → main / root。

## 六、取舍说明

- 原书为纯扫描件，无法抽文本，公式 OCR 失真严重；正文按教材结构重写，例题自行验算，不逐字转录。
- KaTeX 走 CDN 三源回退，未内联字体；包体因此保持在 470 KB 量级。需要完全离线时可在构建脚本里替换为本地 KaTeX。
- `_scan/` 仅保留目录页与 OCR 文本，用于说明章节来源，可删。
