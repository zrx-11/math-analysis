## 使用方法

1. 双击 `index.html` 打开总学习手册（离线可用；Mermaid 图联网时渲染，离线显示源码）。
2. 每本书含：学习路径 → 章节精讲 → 概念页 → 测验 → 抽认卡 → 术语表 → 模式库 → 速查表。
3. 部署 GitHub Pages：把本目录全部文件放到仓库根目录，`git push` 后在 Settings→Pages 选 `main` + `/ (root)`。
