# 解题模式库（下册）

## 级数判敛的五步

1. 查通项：$u_n\to0$ 吗？不趋于 0 直接发散。
2. 查题型：正项、交错、还是任意项。
3. 正项：先试比值或根值，$q=1$ 时改用比较、积分或拉贝。
4. 交错：查莱布尼茨条件（单调、趋于 0）。
5. 任意项：先查绝对值，绝对收敛即止；否则用狄利克雷或阿贝尔。

## 函数项级数的两条主线

- 要证一致收敛：先找 $M_n$，套 M 判别法；不行再看部分和是否一致有界。
- 要交换运算：先确认一致收敛，再对连续性、积分、求导逐条使用。

## 多元极限的判断

- 证不存在：找两条路径给不同值。常用 $y=kx$、$y=kx^2$、极坐标。
- 证存在：极坐标下把式子放缩成只含 $r$ 的量，令 $r\to0$。
- 累次极限不能替代重极限，只能用来否定。

## 多元极值的流程

1. 解 $\nabla f=0$ 求驻点。
2. 算黑塞矩阵，判正定、负定、不定。
3. 边界用条件极值或参数化。
4. 比较所有候选点的函数值。

## 重积分化简的顺序

1. 画区域，判 X 型、Y 型、极坐标型。
2. 看被积函数：含 $x^2+y^2$ 优先极坐标，含 $z$ 与柱体优先柱面。
3. 检查对称性：奇函数在对称区域积分为零。
4. 必要时交换次序。

## 曲线曲面积分的选型

| 题目说法 | 用哪个 |
|---|---|
| 弧长、质量、重心 | 第一型曲线积分 |
| 做功、环量 | 第二型曲线积分 |
| 曲面面积、面质量 | 第一型曲面积分 |
| 通量、流量 | 第二型曲面积分 |
| 闭曲线 | 格林公式或斯托克斯 |
| 闭曲面 | 高斯公式 |

## 常见错误清单

- 级数比值法 $q=1$ 时直接判发散。
- 极坐标积分漏掉雅可比 $r$。
- 球面坐标把 $\varphi$ 与 $\theta$ 弄反。
- 格林公式方向取顺时针。
- 第二型曲面积分换侧不变号。
